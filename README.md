# Arushi's game portfolio (React version)

Run locally:  `npm install`  then  `npm run dev`
(Windows PowerShell blocked? use Command Prompt, or run `Set-ExecutionPolicy RemoteSigned -Scope CurrentUser` once.)

Edit your text: `src/content.js` (name, email, Calendly, GitHub, About, Work, Skills, checkpoint content).
Resume: replace `public/resume.pdf`.
Deploy: push to GitHub, import in Vercel (Framework: Vite, build `npm run build`, output `dist`).
